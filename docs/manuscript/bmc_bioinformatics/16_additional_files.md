# Additional files

## Additional file 1

File name: Additional_file_1_Supplementary_Figures_S1-S8.pdf  
File format: PDF  
Title: Supplementary Figures S1–S8  
Description: Combined searchable PDF containing Supplementary Figures S1–S8 with a title page, table of contents, and complete figure legends. Internal panel labels may retain Figure S1–Figure S8 nomenclature. Contents include cohort overview, pairing and sample attributes, full LA single-nucleus localization matrices, per-cohort PCA overview, GSE238242 RNA-side and mural sensitivity, chamber-contribution views, an F4 constituent-program example, and external AF gene-set overlap.
